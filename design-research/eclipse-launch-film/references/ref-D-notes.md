# D (Agentic Fabriq brand board; user upload, 2026-10-29; not in git)

A still board, not a film: a brand identity for an AI-agent identity company, shown across six touchpoints.

**Not a reference (user, 2026-10-29).** The one thing that caught the user's eye is the browser-tab panel (middle
right), which they circled. The FITWAY-style mark and name sit inside a browser tab, and the tab's edge flows into the
toolbar below through a smooth concave curve, so the tab and the bar read as one continuous surface. The coordinator
first misread "التبويبة" (the tab) as typography; corrected. This is an observation, not a rule. The notes below
describe the board for context only.

- **Palette:** Carbon Black #0D0D0D, Soft White #F5F5F5, Steel Gray #7A7A7A, Graphite Navy #1C2633, and one accent,
  Electric Cyan #59EBFF.
- **Signature texture:** pixel and dither fields (checkerboard, dot grid, vertical bars), blended into soft organic
  shapes, in cyan, white and navy.
- **Story layer:** thin curved paths with small lit nodes and tiny uppercase system labels (IDENTITY VERIFIED, EVENT
  LOGGED, ACCESS GRANTED, ACTIVE SESSION). The product's events become the decoration.
- **Mark:** built from pixel squares, set in a hairline frame with corner marks. Large pixel numerals (1. 2. 3.) appear
  on tall feature cards.
- **Type:** a geometric grotesk for the name and headlines, and a monospace-like face in one post.
- **Applications:** feature cards, browser chrome, a social profile, a billboard in a lobby.
- **Against this film:**
  - FITWAY's accent is red, and RULES bans blue.
  - Eclipse's Busy times heatmap is already a grid of cells, a pixel field native to the product.
  - Any event label would have to be one Eclipse really shows.
