# Design research — input, not authority

Reference captures and research write-ups gathered while shaping FITWAY's visual direction.

This directory is **not** in the source-of-truth order in `AGENTS.md` and holds no authority.
Visual composition is governed by Paper, per
[ADR-007](../docs/adr/ADR-007-paper-visual-source-of-truth.md). Behavior, data semantics,
privacy, and security are governed by `FITWAY_PRODUCT.md` and `SPEC.md`. A recommendation,
reject list, or brief in here binds nothing until it is adopted into Paper or an accepted ADR.

Material here differs from `docs/archive/` in one way only: it is not superseded. It is input
that was never authority in the first place.
