# Demo research (for after the design moves to production)

Research gathered on 2026-10-04 for the later demo to the gym's owner (DECISIONS item 2, "Why"). Read these before
starting the demo's mock-ups, motion-graphics video or explanatory PDF. Evidence and rationale, not authority.

- `motion-graphics.md`: Opus 5.5 motion-graphics examples, the tools people gave it (HyperFrames, Remotion,
  Playwright + FFmpeg), the workflow that works, and the recommended pipeline.
- `gym-current-system.md`: the gym's current system and its vendor, how other gym systems expose turnstile data, and
  how to position FITWAY as a complement, with questions to ask the gym.
