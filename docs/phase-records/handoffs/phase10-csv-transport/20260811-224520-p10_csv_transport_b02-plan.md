## Objective

Make the accepted Phase 10 per-minute CSV generator reachable through the owner-only streamed
oRPC event iterator `admin.analytics.csv` at `/rpc/admin/analytics/csv`. An authenticated owner can incrementally consume the
fixed CSV chunks for one strict inclusive business-day range; anonymous/inactive authentication
is rejected as `401`, staff is rejected as `403`, and rejected requests never begin a repository
read. This slice is complete only when the real RPC transport, cancellation chain, and historical
CSV shape pass direct and disposable-Postgres acceptance tests.

This is the `phase10-csv-transport` worker milestone only. The Owner download interaction,
reporting page, browser/accessibility/visual coverage, and canonical baselines belong to the later
`phase10-ui-csv` slice. The `phase-10` aggregate remains separate.

### Stage 1 — regression-first transport implementation

The worker follows red-green TDD and records each former-failure boundary before source changes.
Direct procedure/transport tests must prove:

1. null or inactive canonical auth is `UNAUTHORIZED`, valid staff is `FORBIDDEN`, and owner access
   succeeds;
2. rejected auth and rejected inputs never invoke the injected reporting iterator;
3. missing fields, unknown keys, wrong array/object/scalar shapes, invalid ISO days, reversed
   ranges, and 367-day ranges reject before streaming, while 1-day and 366-day boundaries pass;
4. the output is a schema-validated async event iterator of strings; the header is delivered as
   the first event before later rows are requested, chunks stay ordered, and completion is clean;
5. calling `.return()` on the oRPC iterator after its first event calls `.return()` on the
   injected iterator and executes handler/injected cleanup exactly once;
6. aborting the procedure call's `AbortSignal` after its first event independently executes the
   same handler/injected cleanup exactly once;
7. an injected iterator that deliberately yields a non-string value fails lazily with
   `EVENT_ITERATOR_VALIDATION_FAILED`, proving the event schema is actually attached.

Duplicate JSON object keys are not observable after standards-compliant JSON parsing and are not
a separate bespoke parser contract. Do not add a raw-body parser to manufacture one.

The minimal implementation should keep the owner guard at the procedure leaf, validate with
`csvRangeInputSchema`, validate yielded chunks with
`eventIterator(reportingCsvChunkOutputSchema)`, and forward the existing context-injected
`streamCsv(input)` iterator without buffering the complete export.

Rollback: one additive worker commit removes the new module/tests and the three leased wiring
edits, leaving the accepted domain/repository and all existing routes unchanged.
