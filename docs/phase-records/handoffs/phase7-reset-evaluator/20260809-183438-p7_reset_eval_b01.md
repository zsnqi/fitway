## Decisions made (with canonical source)

- Worker implementation decision within the activation contract: one requested business day is
  the evaluator unit; persistence may
  request the relevant day(s) and atomically claim the returned stable key in Phase 7 integration.
- ADR-004 and `SPEC.md`: the settings version effective immediately before scheduled close owns
  that close and its configured buffer; a later version does not retroactively alter it.
- Phase 5 command model: an issuance intent is `reset_zero` with `targetValue: null`, issuer
  `system`, and supersession enabled; any recorded Phase 5 command status counts as already
  issued for exactly-once evaluation.
