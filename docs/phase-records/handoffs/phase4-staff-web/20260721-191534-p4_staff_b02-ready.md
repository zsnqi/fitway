## Decisions and behavior

- Authentication uses the frozen `POST /api/auth/staff/pin`, `GET /api/auth/session`, and
  `POST /api/auth/logout` contracts with credentialed requests and HttpOnly cookie sessions;
  the client does not persist or log PINs/tokens.
- The PIN field accepts only 6–12 Western digits. Authentication failures are
  non-enumerating, and `429 Retry-After` temporarily disables submission without an
  assertive live-region countdown.
- `/staff` consumes the typed `staff.operationalSnapshot` oRPC leaf. Capacity and the exact
  ten-field server-evaluated health block appear only on this authenticated surface.
  Transport failures override cached query data so a failed refresh can never remain
  presented as live; unavailable is reserved for the server's domain state.
- Occupancy count is omitted for closed/unavailable snapshots. Stale, unavailable, closed,
  loading, and transport failure each have distinct localized semantics and visuals.
- `/admin` consumes the typed owner session leaf, redirects unauthenticated users to login,
  renders localized `403` content for staff, and exposes the owner shell only to owners.
- The approved FITWAY visual baseline remains authoritative. The implementation uses the
  existing identity and tokens, a restrained VIS-001 atmosphere softening, and content-
  adaptive VIS-004 operational surfaces without changing locked public hierarchy.
- Dynamic numeric/time runs are bidi-isolated while retaining Western digits. Focus-visible
  treatment is inherited from the existing global UI rule and asserted via computed style.

## Review findings resolved

Fresh standards and specification reviews found four actionable gaps; all were resolved
before the candidate gate:

- cached live data could outrank a background transport error — error now takes precedence,
  with a browser regression covering success followed by `503`;
- the rate-limit countdown could repeatedly announce in `role=alert` — the announcement is
  now stable while the internal retry timer advances;
- the English functional flow was incomplete — login, logout, staff entry, and owner shell
  now have an English/LTR browser flow;
- dynamic RTL numeric/time runs needed isolation — message interpolation now uses bidi
  isolates.

The focus-visible concern was disproved by the existing global focus rule and is now guarded
by computed-style browser assertions. A repeated occupancy-state branch was reviewed as a
non-blocking judgment call; it remains localized in one presentation component and has
state-complete tests, so no speculative abstraction was introduced.
