## Decisions made (with canonical source)

- Projection shape is exactly the nine frozen columns `deviceId, sequence, processStatus,
  cameraStatus, feedStatus, detectorFps, edgeObservedAt, receivedAt, updatedAt`; statuses
  use the new `edge_health_status` enum; `detector_fps` is `double precision` guarded by a
  `null or (>=0 and < 'infinity')` check so `null` means unknown (not zero) and NaN/∞ are
  rejected. No seed rows. (`SPEC.md` 414–428)
- The projection is written only inside the accepted contiguous-live-push transaction,
  after minute upserts / current-state update / device advancement. Replay, sequence gap,
  validation failure, disabled device, and rollback never reach or commit the write.
  (`SPEC.md` 420–428, ADR-003)
- Freshness/condition evaluator (`packages/api/src/health/evaluator.ts`): `current` when
  trusted `receivedAt` age is strictly below `operationalStaleAfterSeconds`, `stale` at
  equality and beyond; `unavailable` when there is no projection, no usable active device,
  or a disabled device, with every raw field/time nulled except an independently known
  `lastSeenAt`. Condition precedence any `failed` → `failed`, else any `degraded`, else any
  `unknown`, else `healthy`; stale never erases last-known flags. (`SPEC.md` 430–454)
- `staff.operationalSnapshot` DTO (`operationalSnapshotSchema`) returns exactly the
  ten-field `health` block plus `schemaVersion`, `computedAt`, the public occupancy fields
  (nested `occupancy`, reusing the shared payload builder — no recomputation), authorized
  `capacity`, and source detail. No speculative Phase 5 command fields. (`SPEC.md` 430–457)
- The leaf is mounted on the existing integrated `staffProcedure` (staff|owner), so
  missing/expired auth → `401` and the guard family's `403` wrong-role path is unchanged.
  Transport/read failures propagate as errors and are never converted into `unavailable`.
  (ADR-002, `SPEC.md` 452–454)
- `context.ts`: `readOperationalSnapshot` is a required option of `createContext` (the
  server must wire it) but is typed optional on the shared `Context` so the pre-existing,
  forbidden-to-edit `packages/api/src/auth/session-router.test.ts` `call({ auth })` literals
  still type-check; the leaf guards defensively. This is the minimal reconciliation of the
  lease-mandated context injection with a read-only auth surface.
