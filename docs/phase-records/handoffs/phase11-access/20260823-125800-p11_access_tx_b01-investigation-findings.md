Findings

Answer: The owner access refusal surface is small and single-sourced. All typed refusals are declared as one union, `AccessRuleCode`, in `packages/auth/src/access.ts`; the transport converts every `AccessRuleError` uniformly to `BAD_REQUEST` with the code attached and rethrows everything else. The staff provisioning path already closes its unique-collision race by classifying driver SQLSTATE 23505 through a cause-chain walk; the owner provision path has no such classification, so a collision on `auth_principals_owner_email_unique` escapes `run()` uncaught and becomes a 500. Integration tests live in one file with an established racer pattern (`Promise.all` over N raw RPCs, exactly one 200, losers asserted by status + code).
