28. **The pre-commit evidence check understands a merge** (the user, 2026-11-07, "Fix the hook first", asked whether to
    commit the merge of `owner-followup-r04-build` into the coordinator line with the hooks skipped). That merge
    (r04 decision 112) was refused by the `staged-evidence` job: it reads `git diff --cached` against HEAD, so every
    line the other branch brings counts as added, and 100 or so lines of briefs committed on the build branch in
    October, before the rule of 2026-11-01, were judged as new. The fix: while a merge is in progress, a line is added
    only when it is added against every parent, and a file is new only when no parent has it. Hooks are not skipped.
