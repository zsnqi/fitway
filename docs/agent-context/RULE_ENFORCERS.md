# Which check enforces each rule

Each rule an agent follows in `AGENTS.md`, `docs/agent-context/WORKING_AGREEMENTS.md` and `docs/WORKFLOW.md`, with the
check that rejects a violation, or `written only` where none does. Before searching the code for a check, look here:
a `written only` rule has no check to find. "part:" says which part of a rule a check covers. CI runs only `pnpm
verify:fast`; every other command enforces only when someone runs it. Branch protection covers `main` only (r04
decision 63). Compiled 2026-10-28 by a read-only researcher from the code and checked by the coordinator on samples;
`pnpm check:agent-context` keeps every command and file named here existing. A rule that gains or loses a check
changes its row in the same commit.
