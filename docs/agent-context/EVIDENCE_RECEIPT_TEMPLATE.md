# Evidence receipt

## Receipt fields

- Status:
- Milestone / task class:
- Base commit / candidate commit:
- Branch / worktree / run ID:
- Owned paths / shared leases used:
- Decisions made (canonical source and selector):
- Changes by file:
- Validation commands and results:
- Rendered and accessibility evidence:
- Independent verifier findings:
- Named historical evidence (only when requested):
- Remaining work or exact blocker:
- Exact resume command:
- Stop/escalation conditions:

## Validation commands and results

Record the exact command, run ID, result, and artifact path. Convenience aliases are not reusable
authoritative evidence.

## Rendered and accessibility evidence

Name exact frames, locales, directions, widths, states, and the reviewer. A green detector or
canonical hash is provenance, not a visual-quality judgment.

## Independent verifier findings

Record findings by severity with file/line evidence. The verifier receives the packet, commits,
acceptance criteria, commands, and artifacts—not implementation reasoning.

## Named historical evidence

List only the explicitly requested terminal record, predecessor, incident, or audit pointer. Do not
copy the history file or promote historical status to current authority.

## Exact resume command

Use a current repository-relative command. Never resume from an absolute historical worktree path.
